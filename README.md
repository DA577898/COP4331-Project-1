# Contact Manager for Team 20

A full stack contact manager application that allows users to securely authenticate, add, edit, delete, and update their personal contacts.

## View  here: 
[https://cop4331project.dev/](https://cop4331project.dev/)

## Stack
Frontend: HTML, CSS, JavaScript
Backend: PHP (LAMP Stack)
Database: MySQL
